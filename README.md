## SEO and site foundation

- `robots.txt` — crawler access rules and sitemap declaration
- `sitemap.xml` — public URL list for search engines
- `_redirects` — canonical host and clean URL redirects
- `site.webmanifest` — brand and browser/app metadata
- `assets/jingyue-logo.png` — website logo
- `assets/jingyue-favicon.png` — PNG browser and mobile icon
- `favicon.ico` — legacy browser favicon
