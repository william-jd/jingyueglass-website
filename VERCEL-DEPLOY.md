# Jingyue Glass Vercel Deployment

This is a static HTML export of the current Jingyue Glass website, prepared for Vercel.

## Deploy with Vercel Dashboard

1. Create or select a Vercel project.
2. Import this folder or upload the ZIP archive.
3. Framework Preset: **Other**.
4. Build Command: leave empty.
5. Output Directory: `.`
6. Install Command: leave empty.
7. Deploy.

The project includes `vercel.json`, clean URL settings, and long-lived caching for files under `assets/`.

## Deploy with Vercel CLI

```bash
npm i -g vercel
vercel
```

When prompted, use the project directory containing `index.html` and `vercel.json`.
