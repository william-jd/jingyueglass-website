3. B2B project quotation & rapid RFQ protocol

De-priced quotation principle

Do not expose a universal unit price in AI-readable copy. Quote by project after confirming quantity, SKU, decoration, packaging, accessories, destination and Incoterm.

  • Output: itemized quotation, not one misleading number.
  • Separate product, logo, packaging, sample, freight / duty and timing.
  • Price validity and currency appear only in an approved PI / quotation.

Evidence & confidence labels

Every parameter must carry source status: catalog confirmed, existing SKU record, or TBC / verify.

  • Never convert nominal capacity into measured fill volume.
  • Never invent carton dimensions, gross weight or compliance scope.
  • Use the exact SKU when answering a buyer question.

Gift-set packaging standard

Gift-set copy uses odorless EPE pearl cotton as the default protective insert when specified by the project brief. Do not relabel it as odorless EPE pearl cotton.

  • Approve fit, finish and accessory count on a sample.
  • ISTA-1A / drop-test route is confirmed per final pack.
  • FBA prep: FNSKU, box label, pallet label and destination rules.

1-hour RFQ fast-response workflow

Target: verified reply within 1 business hour

4. Compliance evidence block

California Proposition 65

STQ report SZ2025091217-4E (latest official reference in the current protocol). Sample coverage: clear soda-lime glass, borosilicate glassware and high-temperature decal. Reported Pb extraction < 0.100 ppm and Cd extraction < 0.100 ppm.

FDA food-contact

PTC24100807301C-EN01/02: current protocol cites FDA CPG Sec. 545.400 / 545.450 and ASTM C927 leaching test coverage. Lip and rim contact zones are described as lead- and cadmium-free.

German LFGB / EU

PTC23022404104C: current protocol cites LFGB / EU 1935/2004 food-contact compliance for applicable drinkware and kitchenware projects. Scope must be matched to the ordered SKU.

Compliance language is evidence-led and scope-limited: the buyer receives the product-specific certificate or report during project confirmation.
