Procurement framework

Two quotation routes

The quotation process starts with the level of customization—not a generic public price range.

Existing Gift Set + Custom Branding

For projects using an existing glassware and box configuration with customized artwork or printed components.

  • Confirm current set availability and component list
  • Review logo file, personalization and decoration positions
  • Confirm sample route, MOQ and required delivery date

Bespoke OEM Gift Program

For new box dimensions, custom accessory combinations, special finishes or new product structures.

  • Define product combination and target presentation

Gift-box insert standard

Odorless EPE pearl cotton

Wooden-box and gift-box sets use EPE pearl cotton inserts to cushion the glassware, fit the selected components and provide a neat, odor-free presentation. Final density, color and cavity layout are confirmed with the packaging brief.
